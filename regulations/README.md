# Regulation documents

Place the regulation PDFs used by the RAG component in a local directory and
pass that directory through `--regulation-pdf-dir`.

The index builder requires the `pdftotext` command from Poppler.

## Corpus sources

The paper lists these four documents. Retain the exact downloaded PDF versions
and record their SHA-256 hashes with the generated chunk/index manifest.

| Document | Official source |
|---|---|
| Regulations on the Administration of Programs for Minors | https://press.nppa.gov.cn/zcfg/202312/t20231205_820768.html |
| Detailed Rules for Online Short Video Content Review (2021) | https://www.nrta.gov.cn/art/2021/12/15/art_113_58926.html |
| Provisions on the Administration of Internet Audiovisual Program Services | https://press.nppa.gov.cn/zcfg/202312/t20231205_820770.html |
| Provisions on the Administration of Radio and Television Program Production and Operation | https://press.nppa.gov.cn/zcfg/202312/t20231205_820765.html |
